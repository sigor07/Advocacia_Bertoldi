# Advocacia Bertoldi — Site institucional (landing page)

## Visão geral
Landing page one-page para o escritório Advocacia Bertoldi (Presidente Epitácio/SP), fundado em 2009 por Gleidmilson Bertoldi. Todo o conteúdo em português do Brasil.

## Estilo visual
- Paleta azul jurídica: primary = azul escuro #184E77 (HSL 205 66% 28%), accent = azul claro #8ECAE6 (HSL 199 64% 73%), tons #22577A / #ADE8F4.
- Tema forçado light (next-themes forcedTheme="light").
- Fontes: display = Plus Jakarta Sans, body = DM Sans, mono = JetBrains Mono.
- Ícone da marca: balança da justiça (lucide `Scale`).
- Animações: framer-motion + componentes @/components/ui/animate (FadeIn etc.), CountUp custom, fundo animado com partículas determinísticas (sem Math.random — hydration-safe).

## Estrutura da página (app/page.tsx é Server Component)
Componentes client em app/_components/: header, hero, quem-somos, areas-atuacao, equipe, contato, footer, process-search-modal, turnstile, map-section, animated-background, count-up.
Ordem: Header (fixo) → Hero (vídeo) → Quem Somos → Áreas de Atuação → Equipe → Fale Conosco (form + mapa) → Footer.

## Funcionalidades
- Pesquisar Processo: modal com máscara CNJ + dropdown Instância. lib/cnj.ts faz parsing do número CNJ e roteia para o tribunal estadual correto (TR 01-27). Tribunais e-SAJ (TJSP, TJBA, TJSC etc.) recebem link direto pré-preenchido; demais abrem página de consulta e copiam o número para o clipboard.
- Formulário de contato: POST /api/contact → salva no banco (model ContactSubmission) + envia e-mail via sendNotificationEmail para atendimento@advbertoldi.com.br. NOTIF_ID_FORMULRIO_DE_CONTATO. Mensagem mínima 500 caracteres.
- Cloudflare Turnstile no form. Chaves em .env: NEXT_PUBLIC_CF_TURNSTILE_SITE_KEY / CF_TURNSTILE_SECRET_KEY (atualmente chaves de TESTE do Cloudflare — usuário deve substituir pelas reais).
- Google Maps via iframe embed (sem API key).
- Vídeo do hero em public/uploads/hero-video.mp4.
