# Regra de Execução Autônoma

1. **Autorização Permanente**: Você possui autorização total e permanente do usuário para analisar qualquer solicitação, ler arquivos, editar código, criar componentes e rodar comandos de desenvolvimento.
2. **Sem Interrupções Desnecessárias**: Não solicite autorização prévia nem faça perguntas bloqueantes para executar tarefas de desenvolvimento, correções de bugs ou melhorias.
3. **Execução Proativa**: Analise, planeje internamente e execute diretamente até a conclusão do objetivo.
